Auto-kick dropped Remote Control sessions

When a session's Remote Control link to the phone drops while claude keeps working, crr can restart it (at a safe turn boundary) so it reconnects. Turning this off keeps the badge — you lose the automatic action, not the diagnosis. A session can also opt itself out individually on its card; this switch is a hard override that beats every per-session choice.

Excluded directories

Transcripts under these directory names never appear as Discoverable. Useful for tools that drive Claude Code themselves and leave transcripts behind (claude-mem's observer sessions are excluded by default). Matching ignores - vs / vs ., so .claude-mem and claude-mem both work.
